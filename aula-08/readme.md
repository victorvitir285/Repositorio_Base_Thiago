# Aula Flask - Criação de API

## O que é API

    É um conjunto de regras que permite a comunicação entre diferentes softwares.
    Ex. E-commerce e correios, restaurante e whatsapp, Uber e wazer

## Método HTTP

    Existem vários métodos, vamos estudar o HTTP

        -GET: "PEGAR" uma informação, solicitar o servidor.
        -POST: "ENVIAR" uma informação ao servidor.
        -PUT: "ATUALIZAR" uma informação.
        -DELETE: "APAGAR" uma informação.
        -PATCH: "ATUALIZAR PARTE" de um informação.

     obs: Associar métodos HTTP com "CRUD"

        - CREATE (POST)
        - READ   (GET)
        - UPDATE (PUT)
        - DELETE (DELETE)
